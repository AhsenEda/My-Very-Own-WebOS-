# My-Very-Own-WebOS-

My first own Web OS 

Desktop:
- Real-time clock updating every second
- Windows you can click and drag around
- App shortcuts to launch programs

The Prologue (Book Journal):
- Log books with ratings, dates, and short reviews
- Manage a separate reading list
- Drag and drop cards to reorder them

Saves all entries automatically in your browser

Tech Used:
HTML, CSS and JavaScript
